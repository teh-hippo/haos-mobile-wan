## 1.0.3

- Add matching Start and Stop controls to the documented Home Assistant
  dashboard while keeping MQTT entities monitoring-only.
- Consolidate single-use MQTT discovery and options-migration helpers without
  changing runtime behaviour.
- Remove the arbitrary source line-count contract and documentation wording
  tests while retaining complexity, typing, coverage, security and release
  gates.
- Replace duplicated repository documentation with one concise overview and
  one operational guide.
